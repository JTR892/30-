# 焊缝X射线裁剪图像自监督表征与聚类研究

[![CI](https://github.com/JTR892/30-/actions/workflows/ci.yml/badge.svg)](https://github.com/JTR892/30-/actions/workflows/ci.yml)

**工作题目：不同训练数据规模下空间注意力对焊缝X射线裁剪图像自监督表征学习与无监督聚类表现的影响。**

本研究拟使用团队现有、标记为DR_SD的焊缝X射线二分类图像。研究者报告的目标数量为15,194张，并认为该数据与Wang等（2025）论文所用数据相对应。Wang等报告了15,194张数字X射线图像，缺陷与非缺陷图像数量平衡；但这一文献记录不能证明团队本地文件与论文数据逐文件相同。本地文件身份、裁剪来源链、实际可读数量和去重后数量均须以本地审计结果为准。不得仅凭数量相同认定数据完全一致。

参考论文：Wang等（2025），[On the effect of the attention mechanism for automatic welding defects detection based on deep learning](https://doi.org/10.1016/j.eswa.2025.126386)。

## 研究边界（v0.4）

- **观察单位：**一张焊缝区域X射线裁剪图像，不是完整底片，也不是缺陷框。
- **工作标签：**缺陷 / 无缺陷；实际目录名须通过本地标签映射文件显式指定。
- **数据数量：**15,194张是研究者报告的目标数量，不是本地审计确认的可用图像数量。
- **来源独立性：**当前主实验采用图像级划分，不追溯原始底片或焊口分组。因此，图像级划分不能证明同一底片或焊口衍生的裁剪图像不会跨集合，也不能据此声称底片级独立性或跨底片泛化。
- **XML标注：**目前只记录与图像同目录、同文件主名的候选标注文件路径；尚未解析或验证XML内容。完成文件匹配、坐标、类别和一致性核验前，不开展缺陷区域分析。
- **目录结构：**当前审计脚本按图像相对路径的第一层目录名映射类别。运行前须确认DATA_ROOT直接包含两个类别目录；若实际层级不同，应先修改并测试脚本，不要为适配脚本而移动或重命名原始数据。

## 核心研究问题

1. 在train划分内部分别使用10%、50%、100%的无标签图像子集时，增加空间注意力是否改变缺陷/无缺陷图像的聚类表现？
2. 聚类表现的变化是否伴随特征几何和聚类稳定性的变化？

## 预设实验方案

- **Baseline：**ResNet18 + SimCLR。
- **Attention：**在相同训练设置下增加CBAM空间注意力分支。当前方案只使用空间分支，不是完整CBAM，也不提出新的注意力算法。
- **初始化与训练：**两种模型计划使用相同的ImageNet监督预训练ResNet18权重初始化。目标域SimCLR对比训练不使用缺陷/无缺陷标签。因此，应表述为“外部监督预训练初始化 + 目标域自监督训练”，不能将整个流程称为完全无监督。
- **训练数据比例：**10%、50%、100%均以train划分为分母，不是全体目标图像的比例。三个子集在train内部随机嵌套抽样，不按类别标签分层；模型训练清单不包含类别标签。
- **数据划分：**按缺陷/无缺陷类别分别进行图像级分层，目标比例约为train / 聚类拟合集 / test = 80% / 10% / 10%。代码按类别分别取整，实际样本数量和比例以生成的划分清单及报告为准。
- **聚类：**使用K-means，固定K=2。K取自已知二分类任务，属于已知簇数条件下的无监督聚类，不代表模型发现了未知缺陷类别。真实标签不传入K-means拟合或测试样本簇分配。
- **评价指标：**ARI为主要外部指标；AMI、NMI为辅助外部指标；Silhouette为内部结构指标。特征几何、kNN purity和聚类稳定性作为事后诊断。依赖真实类别标签的分析须在分析方案冻结后进行，并按协议解封相应标签。
- **主要比较：**令
  `Δ_s(r) = ARI_attention,s(r) - ARI_baseline,s(r)`，
  `C_s = Δ_s(10%) - Δ_s(100%)`。
  同时报告50%结果及三个规模下的原始配对差。C_s为正表示注意力相对ARI收益在10%训练规模下大于100%训练规模；这不意味着Attention在10%规模下必然优于Baseline。
- **训练预算：**主比较拟固定batch size和optimizer steps，以控制更新次数。较小子集因此可能被重复采样更多次；Attention分支也会增加计算量。应记录各规模的唯一图像数量、图像曝光次数、实际训练时间、吞吐和峰值内存。固定steps不等于相同图像曝光次数、FLOPs或墙钟时间，因此不能把结果解释为纯粹的样本数量因果效应。

## 本地数据与算力任务

复制`config/label_map.example.json`为`config/label_map.local.json`，将键替换为实际类别目录名，值分别对应`defect`和`no_defect`。确认DATA_ROOT直接包含两个类别目录后执行：

```sh
make install
make audit DATA_ROOT="/actual/binary_dataset"
make split
make test
make paper
```

M1 Max环境检查与合成数据MPS冒烟测试：

```sh
python -m pip install -r requirements-mps.txt
make environment
make mps-smoke
```

合成MPS smoke使用随机合成图像和普通ResNet18进行短程前向/反向测试，只用于检查基本MPS执行能力；它不代表SimCLR双视图与空间注意力模型在真实图像上的训练吞吐，也不能替代真实图像Pilot。详细步骤见[本地执行手册](docs/LOCAL_EXECUTION.md)。

## 数据审计与标签文件说明

- 审计脚本对原始图像执行只读检查，输出图像清单和审计报告；实际文件数、可读数、尺寸、类别分布和异常情况以本地报告为准。
- SHA256用于识别**文件字节级完全重复**。它不能保证识别重新编码但像素相同的图像、近重复图像，或来自同一底片/焊口的不同裁剪。
- 划分脚本会对文件字节级完全重复项进行去重；若完全相同的文件对应冲突标签，则停止划分并要求人工核查。
- 类别标签用于分层划分；目标域表征训练、训练子集抽样、K-means拟合和簇分配不使用类别标签。外部聚类指标及类别条件事后诊断需要在分析方案冻结后使用标签。
- `test_labels.locked.csv`通过本地文件权限作操作性保护。在支持POSIX权限的环境中，脚本尝试设置为仅文件所有者可读写；这不是加密，也不是不可绕过的安全隔离。实验期间不得用测试标签进行训练、调参或模型选择。
- 原始图像、真实路径、标签映射、数据清单、测试标签、模型权重和训练产物不得上传公开GitHub。
