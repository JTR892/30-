## 主要修改对照

| 位置 | 原表述或原有问题 | 修订内容 | 修订理由 |
|---|---|---|---|
| 数据来源 | 容易将论文报告的15,194张图像与团队本地文件联系得过于紧密 | 明确15,194张是研究者报告的目标数量；论文报告同样数量不能证明本地文件逐一对应 | 避免以数量相同替代文件级来源证据 |

## 修订后保留的研究边界

1. 研究对象仍为团队现有、标记为DR_SD的二分类焊缝X射线裁剪图像。
2. 15,194张仍是待本地审计确认的目标数量，不作为已核实本地样本量。
3. Baseline仍为ResNet18 + SimCLR；Attention仍为增加CBAM空间分支的对照方案，不称完整CBAM或新注意力算法。
4. ImageNet监督预训练初始化与目标域自监督训练必须分别说明。
5. 训练比例仍以train划分为分母，子集在train内随机嵌套抽样且不按标签分层。
6. K-means仍固定K=2；标签不参与K-means拟合和簇分配。
7. ARI仍为主要外部指标；AMI、NMI为辅助外部指标；Silhouette为内部指标；特征几何、kNN purity和稳定性为事后诊断。
8. 固定优化步数造成的曝光次数差异仍需记录，不将结果解释为纯粹样本数量因果效应。
9. 不新增实验结果、性能数字、已完成状态或未经验证的创新性宣称。
