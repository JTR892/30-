# 正式模型训练实现计划 v0.4

**状态：BLOCKED — 完整训练器尚未实现。**

## 当前事实
仓库已经定义研究对照：ResNet18+SimCLR baseline，以及在layer4后、GAP前增加CBAM spatial branch的Attention变体。但当前仓库没有完整训练器，不能仅凭研究协议或MPS smoke脚本启动正式实验。

## 需要实现的组件
1. **数据集读取**：只读取无标签训练清单中的图像路径；不得从目录解析训练标签。
2. **预处理**：依据真实审计结果确定灰度/位深转换、尺寸处理和归一化；保留纵横比，不随意拉伸；配置必须可追溯。
3. **双视图增强**：结合焊缝射线图像特点审查增强；不得直接照搬可能破坏缺陷结构的自然图像增强。
4. **模型**：ResNet18+SimCLR projection head；Attention版本仅增加CBAM spatial branch。两版本共享骨干初始化和训练设置。
5. **初始化披露**：当前配置计划使用ImageNet监督预训练ResNet18权重。目标数据训练不使用目标标签，但外部预训练含监督信息；论文不得称整个流程完全无监督。
6. **损失函数**：实现并测试NT-Xent/InfoNCE，检查batch、温度参数、数值稳定性和正负样本索引。
7. **训练器**：支持固定optimizer steps、配对随机种子、断点续训、日志、耗时、吞吐、样本曝光次数和内存记录。
8. **特征提取与聚类**：投影头前GAP特征；K-means仅在无标签聚类拟合集拟合，test最近中心分配。
9. **评价**：冻结后才读取test标签，计算ARI/AMI/NMI、类条件几何、kNN purity和稳定性。
10. **复现记录**：记录代码commit、数据清单哈希、label-map哈希、配置哈希、权重哈希、随机种子和失败运行。

## 训练规模与预算
- 10/50/100%均指train分区内部的比例。
- 主比较拟固定batch与optimizer steps。较小子集会有更多重复曝光；空间注意力也增加计算量。记录唯一图像数、曝光次数、墙钟时间、吞吐和峰值内存。
- 先保证3个配对种子、18次实验，作为探索性最低矩阵；资源允许时扩展到5个配对种子、30次。
- 任何矩阵规模决定必须在test标签解封前完成，并记录依据。不得只保留成功或有利的种子。
- 不做额外匹配epoch敏感性实验时，不把结果解释为纯粹的样本数量因果效应。
