# 研究协议 v0.4（DRAFT）

## 研究目标
检验在目标域缺陷/无缺陷标签不参与表征训练时，空间注意力是否改变焊缝X射线裁剪图像的自监督表征和已知K=2无监督聚类表现，以及注意力的相对收益是否随训练图像数量变化。

## 数据与来源
目标为团队现有、标记为DR_SD的二分类焊缝X射线图像，研究者报告目标数量15,194张，并认为与Wang等（2025）论文数据相对应。Wang等论文报告15,194张数字X射线图像且缺陷/非缺陷数量平衡，DOI为10.1016/j.eswa.2025.126386。团队本地文件与论文图像逐文件身份、裁剪来源链、实际可读数量尚未独立核验。15,194是目标数量，不是审计结果。

观察单位为一张焊缝区域裁剪图像。工作标签defect/no_defect。原始底片/焊口映射不作为主实验硬门槛；不得声称底片级独立性。XML是可选扩展。

## 划分与标签纪律
- 图像级按二分类标签分层80/10/10划分train、聚类拟合集（代码目录名calibration）和test；披露标签参与分层。
- 三个模型输入清单均不含标签；test标签单独保存并锁定。
- 10/50/100%均为train划分的比例；训练子集在train内随机嵌套抽样，不按标签分层。
- 标签不用于目标域表征训练、子集抽样、checkpoint/超参数选择、K-means拟合或测试样本簇分配。
- 在分析协议冻结并解封test标签后，标签可用于ARI/AMI/NMI、类条件特征几何和kNN purity等事后评价，不得反馈模型选择。
- 图像级划分不能保证同源裁剪不跨集合，论文不得声称底片级独立性或跨底片泛化。

## 模型与预算
Baseline为ResNet18+SimCLR；Attention在同骨干layer4后、GAP前增加一个CBAM空间分支。仅用空间分支不称完整CBAM。计划使用配对ImageNet监督预训练权重，论文须披露外部监督初始化。
主比较固定batch与optimizer steps；小子集会重复曝光更多，空间分支也会增加计算量。记录唯一图像数、曝光次数、吞吐、墙钟时间和峰值内存。固定steps不等于相同FLOPs、墙钟时间或曝光次数。
目标矩阵先保证3个配对种子、18次探索性实验；资源允许再扩展5个种子、30次。不得只报告有利种子。

## 聚类与评价
K-means主实验固定K=2，K来自已知二分类任务，不是模型发现。标签不传给K-means，不提供簇—类别映射。K-means仅在固定无标签聚类拟合集特征上拟合，test最近中心分配。
ARI为主要外部指标，AMI/NMI辅助，Silhouette内部描述。kNN purity、类内/类间距离只在test标签解封后作事后诊断。稳定性以不同K-means初始化和不同训练种子所得test分配之间的两两ARI衡量。

## 主要比较
Δ_s(r)=ARI_attention,s(r)-ARI_baseline,s(r)。
主要规模交互对比C_s=Δ_s(10%)-Δ_s(100%)。C_s为正表示注意力的相对ARI收益在10%规模下比100%规模更大，但不表示注意力在10%时必然优于基线。
次要汇总A_s为三个训练规模下Δ_s的平均值。报告每个种子和每个规模原始结果；少量种子只作探索性描述，不声称统计显著。

## 冻结
先真实数据审计、类别映射、SHA256、许可和划分；再运行真实图像Pilot，确定尺寸、增强、batch、优化器、温度、学习率、更新步数和checkpoint规则；之后冻结参数、split/label-map哈希、K=2、分析规范和代码版本，锁定test标签。DRAFT不授权正式训练。

## 风险
本地文件与论文数据身份未核验；图像级划分可能有同底片相关裁剪跨集合；二分类目录标签需核验；15,194不是已审计文件数；固定steps导致重复曝光差异；ImageNet初始化含外部监督；注意力可能无收益。热图、Silhouette或二维图不构成因果证据。
