# 标注与判读规则草案 v0.1 · 2026-11-27

用途：组织原图、XML和不同标注版本的人工复核。状态为DRAFT；适用的检测/验收文件尚待提供者确认。以下为拟议研究工作流程，不是工业验收规程；没有专家批准或逐图诊断结论。

配套：[类别字典](LABEL_DICTIONARY_DRAFT.md)、[人工确认问题](HUMAN_CONFIRMATION_DRAFT.md)、[术语资料与访问深度](ANNOTATION_REFERENCES.md)。

## 1. 证据和观察单位

观察单位为当前收到的一张焊缝区域图像；XML对象是其上的标注记录。图像、对象、解码像素组、焊口/源片四个单位分别记账。当前文件尺寸不证明逐张裁剪史，像素唯一不证明独立焊口。

保留原图/XML、原目录、原名称、原坐标、哈希、任务ID及每个标注版本。所有修订另存派生表并指回原记录；不移动、覆盖或删除源文件。完全相同像素只合并复核任务，不通过副本数量或文件顺序裁定真值。

## 2. 先确认配对和坐标，再开展对象对照

同目录同主名、尺寸一致和filename一致均作为配对线索。出现名称差异时核对导出/重命名记录及对象位置，记录“已确认对应”“未解决”或“建议重配及依据”；这些拟议状态必须由实际复核填写，程序不自动生成。

622份仅tif/tiff后缀差异在现有任务包中登记为名称等价，不因这一点新增错误任务；这一工程规则不认证图像身份。历史folder和Windows path单独作为溯源字段，不优先于图像和标注方记录，也不据此自动重配XML。

坐标确认至少记录：原点基准、终点包含性、单位、参考图像、旋转/翻转/缩放/裁剪过程及是否为粗框。当前只执行0≤x≤width、0≤y≤height包络检查，不指定某种VOC端点约定。xmax=width等边界值是否有效取决于实际约定。

1个逆序对象与3个零跨度对象逐对象保留原值。先确认配对与约定，再记录解释或拟修订坐标。包含端点坐标下相等端点可能表示一像素范围；不能统一删除或自动扩框。逆序也不直接自动交换端点。没有标定，不将像素长度换算为毫米；XML尺寸相符不证明旧框经历过正确裁剪变换。

## 3. 原图显示与判读记录

在原始16位图上记录可判读性、所用软件/显示窗、必要的反相显示、放大及观察位置。现有640像素JPEG和1–99百分位映射用于定位，细小指示及框边界回到原图核对。显示操作记录在工作表，不写回源图；不通过平滑、锐化或生成式增强补出判读证据。

拟先记录无框观察，再查看各XML和目录声明并记录差异。现有复核入口显示原标签，不能将其称为盲审；若后续安排盲审，应明确隐藏内容、人员可见信息及实际执行方式。当前未建立专业确认的正反例图库。

外观、位置和对比度只记录为观察事实。缺陷类型需要结合已确认定义和适用证据；不能单凭“圆点”“细线”或灰度阈值推断类型、成因或验收结论。无法判定时明确记录不确定及缺失证据。

## 4. 对象、图像类型及合格性分开

对象级拟记录：原XML及object_index、原标签/框、实际观察、类型意见、框是否适用于预定区域分析、依据与不确定性。同类多个框不强行合为一个实例；一个粗框也不直接解释为像素级缺陷掩膜。

图像级保存经复核的类型集合和完整性状态。确认只有一个类型，不等于只有一个缺陷；空XML、无XML或只有辅助框均不自动产生正常标签。1,899张原多类型图像保留共存事实；同义/上下位关系确认后才更新派生类型集合。

good保留“研究者说明为合格”的来源事实。检测合格性与研究所需的可见缺陷语义分别确认；本草案不把两者设为等价。“其它缺陷”和“成形不良”须先明确组成和范围，再决定评价用途；保留未知，不为凑类别数强制合并或排除。

## 5. 分歧、裁决与实际责任

建议由具备对应焊缝射线判读经验的人员执行；负责人确认其实际职责和适用要求。先以覆盖问题类型的小批原图试用规则，记录规则不能解决的情形，修订版本后再扩大复核。样本数和人员尚未确定，不把机械索引示例当作已完成试判读。

有分歧时保留各自意见和依据，安排实际可用的合适人员复核或裁决；不能由AI生成第二判读人、投票结果、资质、签名或日期。专家定义与批准字段保持空白，直到真实填写。

填报最低要素：图像/对象及原任务ID、规则/字典版本、原值、观察意见、拟修订值、证据位置、真实人员、日期、分歧和最终状态。拟修订、复核同意及最终批准分开记录；不确定结论也属于有效记录，不用空白冒充阴性。

## 6. 研究使用和变更

质量/来源资格与评价标签资格分别建表。缺陷类型标签不进入表征训练、主训练子集选择、模型选择或聚类拟合；不能按复核类别数量挑选主训练样本。人工标签辅助的审计/预处理决定及外部监督预训练如使用，应披露。

完全重复、已核实同源及未来确定的来源连通组不得跨分区；近重复候选保留证据等级。现成train/val/test已用于预分区审计，未来最终测试和Pilot范围另行冻结，不以现成目录直接放行。

字典、排除规则、来源映射、显示/坐标约定和脚本都保留版本。最终测试后变化标为探索性，不覆盖已冻结主分析。草案完成后数据资格继续HOLD；正式划分、Pilot和训练各按现有协议门槛执行。
