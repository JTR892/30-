# 项目状态 · 2026-11-25 · v0.4

## 研究题目
不同训练数据规模下空间注意力对焊缝X射线裁剪图像自监督表征学习与无监督聚类表现的影响。

## 数据状态
研究对象为团队现有、标记为DR_SD的焊缝X射线二分类图像。研究者报告目标数量15,194张，并认为与Wang等（2025）论文数据相对应。该论文报告15,194张数字X射线图像且缺陷/非缺陷数量平衡，DOI为10.1016/j.eswa.2025.126386。团队本地文件与论文数据的逐文件身份、裁剪来源链和本地实际可读/去重数量尚未独立核验。15,194是目标数量，不是审计结果。

每张焊缝区域裁剪图像作为观察单位。原始底片/焊口映射不作为主实验硬门槛；因此不能声称底片级独立性或跨底片泛化。XML全量核验改为可选扩展。

## v0.4研究设计修订
- 训练比例10/50/100%明确以train划分为分母。
- 目标域SimCLR训练不使用目标标签；ImageNet监督预训练如使用，需披露外部监督初始化。
- K=2为已知簇数条件下的无监督聚类。
- 主要对比改为C_s=Δ_s(10%)-Δ_s(100%)，直接对应低规模与全规模的注意力相对收益差。
- kNN purity和类别条件几何仅在分析冻结、测试标签解封后作事后诊断。
- 固定steps导致小子集重复曝光更多，需记录曝光、耗时、内存，不作纯样本量因果解释。
- Wang等（2025）已研究注意力和特征簇，不能声称首次；潜在差异是目标域自监督训练与训练规模控制。
