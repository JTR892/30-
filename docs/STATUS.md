# 项目状态 · 2026-11-24 · v0.3

研究对象收敛为团队已有 15,194 张二分类焊缝 X 射线裁剪图像。研究者确认数据来自 DR_SD 并对应 Wang 等 2025 年论文数据；15,194 是目标数量，实际可读/去重数量待本地审计。

v0.3 将样本单位改为单张裁剪图像，不要求原始底片/焊口映射；XML全量核验改为可选扩展。新增显式二分类目录映射、SHA256重复检查、图像级分层80/10/10划分、训练清单标签隔离和测试标签独立文件。训练子集在train内标签盲随机嵌套抽样。主K固定2并披露已知簇数。
