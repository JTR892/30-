### 第一轮：事实与来源核验
1. 仓库原题目实际写的是“有限无标签训练数据……无监督聚类”；仓库文件中没有“无监督新生儿”。此前对用户消息中的误词作出仓库文件错误判断是不准确的，已纠正。
2. Wang等（2025）论文报告15,194张数字X射线图像，缺陷/非缺陷数量平衡；论文还讨论空间注意力与缺陷/非缺陷特征簇。论文DOI为10.1016/j.eswa.2025.126386。
3. 团队本地文件与论文数据的逐文件身份、裁剪来源链和本地实际数量未核验。修订后统一标为研究者报告/待核验，不再写成独立审计结论。

### 第二轮：研究定位与概念核验
1. “有限无标签训练数据”容易误读为整个原始数据集规模有限，改为“不同训练数据规模”。
2. 训练规模10%、50%、100%明确以train划分为分母。
3. SimCLR目标域训练不使用目标标签；但当前配置使用ImageNet监督预训练初始化，因此准确说法是目标域自监督训练并使用外部监督预训练初始化，不称全流程完全无监督。
4. K=2来自已知二分类任务，明确称为已知簇数条件下的无监督聚类。
5. Wang等（2025）已经研究注意力及特征簇，研究定位改为自监督目标域训练和训练规模控制，不宣称首次。

### 第三轮：实验设计核验
1. 主要对比从三个规模平均注意力收益，调整为C_s=Δ_s(10%)-Δ_s(100%)，直接对应低规模相对收益是否更大；平均收益A_s降为次要汇总。
2. 固定optimizer steps会使小子集重复曝光更多；空间分支也会增加计算量。修订后要求记录曝光次数、墙钟时间、内存，不将结果解释为纯粹样本量因果效应。
3. kNN purity和类别条件几何需要真实标签，明确只能在分析冻结、测试标签解封后作为事后诊断。
4. 聚类稳定性明确为不同K-means初始化和训练种子分配之间的两两ARI。
5. 三个种子18次实验只标探索性；五个种子30次作为资源允许时的扩展目标，不作未经支持的显著性结论。

### 第四轮：代码与文档一致性
1. config/protocol.json中的“AMI arithmetic”“NMI arithmetic”是错误字段值，改为AMI、NMI。
2. 协议版本升级到0.4，协议门槛代码和测试同步升级。
3. 补充source_film_mapping_required=false，与v0.3取消底片映射硬门槛的研究边界一致。
4. 当前审计代码只读取DATA_ROOT下第一层目录作为类别名，文档新增目录层级检查要求。
5. 代码中的calibration分区在研究文本中称“聚类拟合集”，避免与概率校准混淆。
6. 保留真实数据审计、MPS实测和完整训练器未完成的事实，不将CI成功表述为模型实验成功。

### 第五轮：时间与状态核验
1. 11月20日至12月20日的日期差为30天；首尾日期均列出会出现31个日期标签。将11月20日定义为Day 0，11月21日至12月20日为Day 1至Day 30。
