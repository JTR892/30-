## 一、研究目标与题目

**工作题目：不同训练数据规模下空间注意力对焊缝X射线裁剪图像自监督表征学习与无监督聚类表现的影响。**

研究问题：
1. 在train划分内部使用10%、50%、100%的无标签图像子集时，空间注意力是否改变缺陷/无缺陷聚类表现？注意力相对于基线的ARI收益是否在10%规模下比100%规模更大？
2. 聚类表现变化是否伴随特征几何与聚类稳定性的变化？

本研究不是小样本学习算法研究，也不把15,194张图像整体称为小样本数据集。10%、50%、100%指train划分内部的训练子集比例。

## 二、数据事实、来源与待核验事项

拟使用团队现有、标记为DR_SD的焊缝X射线二分类图像。研究者报告目标数量为15,194张，并认为其与Wang等（2025）论文所用数据相对应。Wang等论文报告15,194张数字X射线图像，缺陷/非缺陷数量平衡；研究对象为T91管对接接头，采用平板探测器和DWDI曝光，原文报告的训练/验证/测试数量为10,636/2,280/2,278。原文也讨论空间注意力与缺陷/非缺陷特征簇。DOI：https://doi.org/10.1016/j.eswa.2025.126386

上述文献事实不能证明团队本地文件与论文数据逐文件相同。以下仍需核验：
- 本地实际文件数、可读数、唯一图像数和类别分布；
- 本地文件与论文数据的文件级对应关系；
- 研究者关于“完整底片裁剪图像”的来源描述及其可追溯程度；
- 目录结构与实际类别文件夹映射；
- 团队数据使用及公开发表权限。

**观察单位：**一张焊缝区域X射线裁剪图像，不是完整底片，不是缺陷框。图像级划分不能证明同一底片/焊口的相关裁剪不会跨集合；不得声称底片级独立性或跨底片泛化。

## 三、预设实验方案

### 3.1 模型
- Baseline：ResNet18 + SimCLR。
- Attention：相同训练流程，在ResNet18的layer4后、GAP前增加一个CBAM空间注意力分支。仅使用空间分支，不称为完整CBAM，也不称为新注意力算法。
- 当前配置计划使用配对ImageNet监督预训练ResNet18权重。若保留，论文应写明“目标域自监督对比训练，使用外部监督预训练初始化”，不能称整个流程完全无监督。

### 3.2 数据划分与训练比例
- 图像级按缺陷/无缺陷标签分层80/10/10划分train、聚类拟合集和test；标签用于分层，必须披露。
- 仓库代码将聚类拟合集目录暂命名为calibration；论文中称“聚类拟合集”，避免与概率校准混淆。
- 10%、50%、100%均以train划分为分母，不是全体15,194张的比例。若train约占总数据80%，则train的10%约相当于全体数据的8%。
- 三种训练子集在train内部随机嵌套抽样，不按标签分层。模型训练清单不含标签。
- K-means固定K=2。K来自已知二分类任务，是已知簇数条件下的无监督聚类；标签不传给K-means拟合或样本分配。

### 3.3 训练预算的解释
主比较拟固定batch与optimizer steps，以控制更新次数；较小训练子集中的图像因此会被重复采样更多次。Attention分支还会增加计算量。必须记录唯一图像数量、样本曝光次数、实际训练时间、吞吐和峰值内存。固定steps不等于相同FLOPs、相同墙钟时间或相同图像曝光次数。若没有额外匹配epoch敏感性分析，论文不得把观察到的变化解释为纯粹的样本数量因果效应。

### 3.4 指标
- 主要外部指标：ARI。
- 辅助外部指标：AMI、NMI。
- 内部指标：Silhouette。
- 事后诊断：类内/类间特征距离、kNN purity、聚类稳定性。
- kNN purity和真实类别条件下的特征几何依赖真实标签，只能在分析方案冻结、测试标签解封后计算，不得反馈模型或超参数选择。
- 稳定性：同一特征集不同K-means初始化的分配两两ARI；跨训练种子的测试样本分配一致性另行报告。稳定不代表语义正确。

### 3.5 主要比较
令Δ_s(r)=ARI_attention,s(r)-ARI_baseline,s(r)。
- 主要对比C_s=Δ_s(10%)-Δ_s(100%)。C_s为正表示注意力的相对ARI收益在10%规模下比100%规模更大；不代表注意力在10%规模下一定优于基线。
- 次要汇总A_s=[Δ_s(10%)+Δ_s(50%)+Δ_s(100%)]/3。
必须报告所有种子、三个规模的原始值、配对差和失败运行。3个种子结果只能作为探索性证据；不凭少量种子宣称统计显著。

### 3.6 与已有研究的区别
Wang等（2025）已经研究焊缝X射线图像中的空间/通道注意力，并分析缺陷与非缺陷特征簇。因此不能将“首次把注意力用于焊缝图像”或“首次分析特征簇”作为创新点。本文拟检验的区别是目标数据标签不参与表征训练，并将训练数据规模作为受控变量，评价已知K=2的无监督聚类。此定位是否形成足够贡献，仍需结合文献排重和真实结果判断。

## 七、风险与压缩顺序

| 风险 | 影响 | 应对 |
|---|---|---|
| 本地可读数量低于15,194 | 数据规模变化 | 以审计结果为准，不补造样本 |
| 本地文件与Wang论文逐文件身份不明 | 数据来源表述不准确 | 使用“研究者报告对应”，不写“已确认完全相同” |
| 目录层级与审计代码不匹配 | 标签映射错误 | 先确认DATA_ROOT和类别文件夹层级，再运行审计 |
| 同源裁剪跨图像级集合 | 可能高估泛化能力 | 披露来源独立性未知，不声称跨底片泛化 |
| M1 Max训练速度不足 | 无法完成30次 | 先保留18次探索性矩阵；必要时缩小结论范围 |
| 小子集重复曝光更多 | 训练规模与曝光量混杂 | 固定steps作为主协议，完整报告曝光；不作纯样本量因果解释 |
| Attention无收益或负效应 | 假设不成立 | 如实报告，不调整指标追求正结果 |
| 训练器实现延期 | 正式实验推迟 | 先完成baseline和attention公平对照；缩减实验而非跳过测试 |
| XML匹配耗时 | 挤占主线时间 | 作为可选扩展，不阻塞主实验 |

**压缩优先级：**先取消XML区域关联等扩展分析；再将5个种子缩减为3个种子；保留三种训练规模与两模型配对对照。如果仍无法完成，提交方法与已完成结果的阶段性初稿，并向导师说明未完成实验，不得编造。
