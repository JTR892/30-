## 一、研究任务与初稿目标

**暂定题目：**《有限无标签训练数据下空间注意力对焊缝 X 射线裁剪图像表征与无监督聚类的影响》

本研究拟使用团队现有的15,194张焊缝X射线二分类裁剪图像。研究者已说明该数据来自团队DR_SD数据，并对应Wang等2025年论文所用数据；15,194张是当前目标数量，最终可用数量必须以本地只读审计结果为准。每张焊缝区域裁剪图像作为一个样本单位，不把它称为完整底片，也不把它称为新建数据集。

核心研究问题：

1. 在10%、50%、100%无标签训练数据规模下，增加空间注意力是否改变焊缝X射线裁剪图像的缺陷/无缺陷聚类表现？
2. 聚类表现的变化是否对应特征空间几何和聚类稳定性的变化？

预设比较：

- **Baseline：**ResNet18 + SimCLR。
- **Attention：**相同训练设置，在ResNet18的layer4后、GAP前增加一个CBAM空间注意力分支；仅使用空间分支，不称为完整CBAM。
- **聚类：**K-means，固定K=2。K=2来自已知二分类任务定义，属于已知簇数条件下的无监督聚类；真实标签不输入表征训练、K-means拟合或测试样本簇分配。
- **主要指标：**ARI；辅助指标为AMI、NMI、Silhouette、类内/类间距离、kNN purity和聚类稳定性。
- **训练矩阵：**目标为3种训练规模 × 2种模型 × 5个配对随机种子，共30次。若M1 Max实际预算不支持，必须在测试标签解封前调整为3个配对种子、18次探索性实验，并在论文中明确说明。

## 六、风险与压缩顺序

| 风险 | 影响 | 应对 |
|---|---|---|
| 实际可读数量低于15,194 | 数据规模与计划不符 | 以审计结果为准，说明剔除原因，不补造样本 |
| 类别映射或标签不可靠 | 聚类外部评价失真 | 先人工核验样本，保留不确定样本记录 |
| 同源裁剪图像跨图像级划分 | 可能高估泛化能力 | 披露图像级划分局限，不声称底片级独立 |
| M1 Max训练速度不足 | 30次实验无法按时完成 | 在测试标签解封前改为18次探索性实验 |
| Attention没有改善ARI | 研究假设不成立 | 如实报告零效应或负效应，讨论适用条件 |
| 训练器实现延期 | 正式训练推迟 | 优先保证Baseline和Attention公平对照，不用不等预算结果作结论 |
| XML匹配与坐标核验耗时 | 挤占主实验时间 | XML区域关联列为可选扩展，不阻塞主线 |

**压缩优先级：**先取消XML区域关联等扩展分析，再将5个种子缩减为3个种子；保留10%、50%、100%三个训练规模和Baseline/Attention配对对照。若仍无法完成，必须缩小论文结论范围并向导师说明，不得把未完成实验写成已完成。
