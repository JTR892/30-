# 研究任务书 v0.2 · 2026-11-22

工作题目：**有限数据条件下空间注意力对焊缝 X 射线图像无监督聚类的影响与表征机制分析**。

“机制”指模型的信息依赖及表征变化，不指焊接缺陷形成机理。题目是研究方向，不代表已取得机制证据；最终主张依据实际完成的分析确定。

## 问题与研究定位

整幅射线图像包含局部缺陷、焊缝结构与成像来源线索。在目标域缺陷类别标签不参与训练时，空间注意力如何改变聚类、表征几何和信息依赖？减少独立训练数据是否改变这些作用？

三个层次是待回答的问题，不预先称为三项已成立的创新。研究价值取决于可重复的新发现及对竞争性解释的检验。已有 CBAM、对比学习和工业局部特征加权聚类均须正面引用。

## 数据与方法

- 主数据为待核验的工业焊缝射线图像；实际目录、有效数量、类别字典、许可、位置标注与来源信息尚未提供。
- 整幅图像是观察单位，独立来源连通组是划分与重采样单位。多缺陷图像不强制赋单标签，未知标签不当正常。
- ResNet18 + SimCLR 对照同骨干加 CBAM 空间分支；配对初始化、嵌套训练组、固定更新预算及无标签校准池。外部 ImageNet 监督预训练如实披露。
- 10%/50%/100% 是审计后训练组的比例，同时报告实际组数、图像数与重复暴露次数。它们是研究因素，不是推荐参数。
- 模型与分析实现均未完成。具体指标与语义分析见 [分析计划](ANALYSIS_PLAN.md)。

## 预期指标与三项待检验问题

| 研究问题 | 核心证据 | 结果边界 |
|---|---|---|
| RQ1：空间注意力是否改变缺陷类型聚类？规模变化是否改变作用？ | ARI 主指标；AMI/NMI 补充；配对效应、跨种子结果及规模交互 | 不预设提高，不规定虚构的目标分数 |
| RQ2：变化对应何种表征结构？ | 类别平衡的类内/类间距离、邻域纯度、聚类分配稳定性 | 紧致不等于语义正确；检查退化和类别覆盖 |
| RQ3：变化依赖缺陷还是采集/来源线索？ | 面积校正的区域关注、来源内/跨来源诊断、匹配区域扰动 | 位置、形态和成像因素需要不同证据；不得由热图直接推断因果 |

正式计划以三个预定规模的 ARI 配对差等权平均为主效应汇总，同时逐规模完整报告；该汇总不代表现实部署中各规模的发生概率。规模交互 C 降为预定次要比较，不能代替 RQ2/RQ3。

## 最大风险与决策

来源泄漏、图像级标签不成立、缺陷类别与设备完全重合，均可能使“缺陷语义”不可识别。优先审计这些条件，而不是增加模型复杂度。

缺少框/掩膜时不能完成定位定量实验；只有框时不能据此精确解释形态。若语义分析证据不足，保留事实并收缩题目与结论。全量几何改善、无效或负效应都保留；不能事后更换主指标来掩盖结果。
