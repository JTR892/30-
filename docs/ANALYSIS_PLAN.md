# 三层分析计划 v0.2（DRAFT）

本文件是设计决定，尚无真实实验结果，也没有实现分析脚本。与 `config/protocol.json` 同步冻结；参数、分析资格、样本选择规则、脚本版本及文件 SHA256 在最终测试标签解封前记录。

## 共同边界

- 特征固定为投影头之前的 GAP 表示，经 L2 归一化；配对模型使用相同图像与来源组。测试图像不参与 PCA、聚类拟合、模型/参数选择或诊断探针训练。
- 类别指标仅在预先定义的单缺陷类型评价子集计算，报告每类图像数、独立来源数、排除与分析覆盖率。标签解封后允许计算描述性统计，但不得据此改模型或主分析。
- 类内/类间均指真实评价类别，不指 K-means 自己得到的簇。三层证据分别报告，指标同向变化不自动构成中介关系或因果链。

## RQ1：聚类效果与数据规模

令 Δ_s(n) = ARI_attention,s(n) − ARI_baseline,s(n)。主效应为 A_s = [Δ_s(10%) + Δ_s(50%) + Δ_s(100%)] / 3，报告各配对种子的 A_s、平均值、标准差和全部逐规模差值。等权是预定设计权重，不是估计的部署分布。

次要规模比较 C_s = Δ_s(10%) − Δ_s(100%)。直接比较 C；不能用一组显著、另一组不显著替代。C 为正也不保证任何规模的 Δ 为正。

AMI/NMI 均规定 arithmetic average_method。K 与拟合池跨模型固定；主结果不能按 ARI/AMI/NMI 中最好看的一个重排。K 敏感性在解封前列定；oracle-K 单列。

当前五个种子同时引入子集顺序和训练随机性，反映这套工作流的联合变异，不能分别归因。按测试来源组重采样的区间反映给定模型的测试抽样不确定性，与跨训练种子变异分开。五个重复不保证检验功效，三次按探索性报告。默认报告效应和不确定性，不通过事后挑选检验取得显著性。若增加正式检验，须冻结检验单位、假设族和多重比较处理。

## RQ2：表征几何与稳定性

归一化后的特征使用欧氏距离。类别 c 的类内距离是不同来源组、同类图像对距离的平均；D_intra 为各有效类别均值的等权平均。D_inter 是每个不同类别对距离均值的等权平均，同样排除同来源图像对。排除规则和计数两模型完全一致。

R = D_inter / D_intra 仅作联合摘要；分母为零或某类无跨组图像对时标明退化/不可估计及覆盖，不静默丢类，不把异常值当零。训练侧另检查原始特征方差与坍缩。全局缩放或退化不是语义改善。

全配对计算可分块精确求和；若资源要求抽样，必须在解封前按图像 ID、固定种子确定共同图像对清单与数量，并标明抽样近似。不得根据距离结果挑选图像对。

kNN purity 使用 k=10，排除自身及同来源组候选，以图像 ID 作为距离相同的固定打破平局规则。先逐图计算同类近邻比例，再按类别等权汇总。少于十个可用跨组近邻的图像标为不可估计并报告覆盖；不看标签临时减小 k。该指标是同一测试集合内的描述性分析，不训练或选择分类器。

稳定性分两类：固定训练表示，对十个预定 K-means 随机种子 1001…1010（各 n_init=20）在相同校准池拟合，再比较相同测试图像的分配；另比较完整训练工作流跨种子的测试分配 ARI。每对分配 ARI 不使用真实类别，可处理簇编号置换。稳定但按设备分组不构成缺陷语义成功。

## RQ3：工业语义与信息依赖

### 分析资格与盲态

在训练侧核验元数据/标注格式与可用性，形成资格报告；最终测试按事先固定规则执行。是否开展每项分析由可用证据决定，不由效果是否正向决定。真实标签与来源交叉覆盖只在冻结后描述，不能用最终测试结果重新划分或选样。缺少设备、曝光或形态记录必须明确缺项。

### 位置与形态

将空间门控权重映射到图像坐标，排除 padding，冻结插值方式。E = [缺陷区域注意力质量 / 全有效区域注意力质量] / [缺陷区域面积 / 有效图像面积]。多框按并集、不重复计面积，零面积/零总质量无效并报告。与同面积且处于焊缝内的非缺陷区域对照；匹配规则在训练侧制定并冻结。

E 描述位置关联，不证明模型决策依赖。基线没有 CBAM 图时不伪造一张图作定位公平对照。若使用归因法跨模型比较，必须先定义无分类头聚类模型的标量目标并做方法适用性检查，不能照抄分类 Grad-CAM。只有框时结论限于区域；形态解释需要可信轮廓/专家测量，不能从框面积推断缺陷形状。

### 来源与成像因素

分别检查同来源内不同缺陷的区分、同缺陷跨来源的结构，报告类别×来源列联表、有效独立组数。按冻结的训练侧规则分箱灰度/焊缝宽度，在标签冻结后作分层描述；分层不能保证消除混杂。若类别与设备无交叉覆盖，则明确无法识别缺陷与设备解释，不能声称已排除来源效应。

平均灰度是图像描述量，不是曝光剂量。焊缝宽度可能有真实工艺含义；是否为无关线索需依据研究目标与领域证据判断。不得宣称任意灰度归一化已移除所有设备差异。

### 扰动响应

预先在训练侧选择扰动算子、幅度、位置匹配、随机种子与可见性验收，不根据测试响应优化掩膜。在模型、归一化和原始校准中心全部冻结后，对测试图像作评价性扰动，不回流训练或重新拟合中心。

比较真实缺陷区域与匹配背景区域的同面积、同算子扰动；量化归一化特征位移、近邻保持和原始中心下的分配变化，再比较 attention 与 baseline 的配对响应差。记录失败的匹配和分析覆盖。多个扰动强度必须完整报告。

去除缺陷后语义可能已改变，因此不把扰动后图像继续当原缺陷类别计算“正确率”。遮挡边缘、模糊与分布偏移是替代解释；采用匹配控制，并由领域人员确认扰动含义。强度变换不等同真实曝光变化，无法保证缺陷可见时不称标签保持。

空间门控置常数/打乱位置只列可选探索性诊断：它同时改变特征分布。若改变表示并重新在校准集拟合中心，应单列重拟合设置；不能与原中心下的输入扰动混为同一机制检验。

## 证据如何支持论文表述

| 观察到的证据 | 可以支持的表述 | 不能直接声称 |
|---|---|---|
| 聚类指标变化 | 给定设置下的效应 | 因为关注缺陷而改善 |
| 高维几何/邻域变化 | 表征结构变化 | 已经找到因果中介 |
| 区域关联、匹配扰动及来源诊断相互支持 | 在这些诊断下支持某种信息依赖解释 | 完整因果机制、所有混杂均已排除 |

这些要求由研究问题提出。方法依据见核心文献表 L13–L17；新文献当前仅核验原始摘要/元数据，不能声称全文复现已完成。
