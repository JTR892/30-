# 两层核心分析计划 v0.3（DRAFT）

## 数据约定
- 一张焊缝区域裁剪图像为观察单位；标签 defect/no_defect。
- 图像级标签分层 80/10/10；训练、校准、测试图像清单不含标签，测试标签单独锁定。
- 训练规模子集从 train 内随机抽样，10% ⊂ 50% ⊂ 100%，不使用标签抽样。
- SHA256 完全重复同标签保留确定性代表并记录；相同内容异标签则停止核验。
- 不追溯原始底片/焊口；图像级划分不能证明来源独立。

## RQ1：聚类表现
Baseline：ResNet18 + SimCLR。Attention：相同设置增加单个 CBAM 空间分支。配对模型共享骨干初始化、图像子集、更新预算、batch、优化器、学习率计划和增强策略。使用投影头前 GAP 特征并 L2 归一化。

主 K=2，来自已知二分类任务定义；属于已知簇数条件下的无监督聚类。K-means 仅在固定无标签 calibration 特征上拟合，测试图像最近中心分配。真实标签不进入聚类器。

ARI 为主指标，AMI/NMI 为辅助外部指标，Silhouette 为辅助内部指标。逐种子报告配对差。令 Δ_s(r)=ARI_attention−ARI_baseline，r∈{10%,50%,100%}；主效应 A_s=[Δ_s(10%)+Δ_s(50%)+Δ_s(100%)]/3。次要规模比较 C_s=Δ_s(10%)−Δ_s(100%)。报告均值、标准差、所有种子和失败运行；不事后挑选指标。

## RQ2：几何与稳定性
在冻结测试特征上用真实二分类标签做事后描述：
- 类内/类间特征距离及比值，防止把整体收缩误判为改善；
- kNN purity，预定 k=10，报告可用近邻覆盖；
- K-means 不同初始化下分配一致性；
- 不同训练种子下分配一致性。
稳定性不等于语义正确。PCA/t-SNE/UMAP仅作可视化；数值评价不使用测试拟合的降维器。

## XML 可选扩展
XML 后续核验文件匹配、坐标系、图像尺寸、类别字典、框/掩膜语义和冲突率后，才可开展注意力区域重叠分析。框只支持粗粒度区域关联，不证明形态或因果。未核验前不在摘要和结论承诺。

## 证据边界
ARI/AMI/NMI变化支持图像级留出集上的聚类变化，不支持跨底片泛化；几何变化支持特征结构变化，不证明因果机制；稳定性不保证语义正确。
