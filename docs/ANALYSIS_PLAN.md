# 两层核心分析计划 v0.4（DRAFT）

## 数据约定
- 一张焊缝区域X射线裁剪图像为观察单位；工作标签defect/no_defect。
- 图像级按标签分层80/10/10划分train、聚类拟合集（代码目录名calibration）和test；披露分层标签使用。
- 训练规模10/50/100%均以train划分为分母；10%子集约占全体可用图像的8%，不是全体数据的10%。
- train子集为随机嵌套抽样，不按标签分层；标签不得用于子集选择。
- SHA256完全重复同标签保留确定性代表并记录；相同内容异标签则停止核验。
- 不追溯原始底片/焊口；图像级划分不能证明来源独立。
- 15,194是目标数量；本地实际可读、去重数量待审计。团队数据与Wang等（2025）论文数据的逐文件身份对应、裁剪来源链尚未独立核验。

## RQ1：聚类表现与规模交互
Baseline：ResNet18 + SimCLR。Attention：相同设置增加单个CBAM空间分支。配对模型共享骨干初始化、图像子集、batch、optimizer steps、学习率计划和增强策略。计划使用相同ImageNet监督预训练权重；目标数据训练不使用目标标签，但外部预训练有监督来源，需在论文中披露。

特征拟采用投影头前GAP并L2归一化。K-means固定K=2，K来自已知二分类任务；只在无标签聚类拟合集特征上拟合，test图像按最近中心分配。K-means不接收真实标签，也不提供簇—类别映射。

令：
- Δ_s(r) = ARI_attention,s(r) - ARI_baseline,s(r)
- **主要对比** C_s = Δ_s(10%) - Δ_s(100%)
- **次要汇总** A_s = [Δ_s(10%) + Δ_s(50%) + Δ_s(100%)] / 3

C_s为正表示注意力的相对ARI收益在10%规模下比100%规模更大；它不单独证明注意力在10%时优于基线。报告50%结果、所有种子和各规模原始ARI。3或5个种子只作探索性/描述性证据，不凭此宣称统计显著。

## 训练预算解释
主比较拟固定batch与optimizer steps，比较不同数量的独立训练图像在相同更新次数下的表现。小子集因此会产生更多重复曝光；Attention分支也增加计算。必须记录实际唯一图像数、曝光次数、墙钟时间、吞吐和峰值内存。固定steps不等于相同FLOPs或相同图像曝光量。若无匹配epoch敏感性实验，不将结果解释为纯粹的样本数量因果效应。

## RQ2：几何与稳定性
在测试标签解封、协议冻结之后，使用真实标签进行事后诊断：
- 类内/类间距离：在L2归一化特征上预先固定距离定义（建议余弦距离），报告两类内部距离和跨类距离，不以整体收缩冒充分离改善；
- kNN purity：预先固定k=10，查询时排除样本自身；使用测试标签，仅为事后诊断；
- K-means初始化稳定性：同一特征集不同初始化所得测试集簇分配之间的两两ARI；
- 跨训练种子稳定性：相同测试图像在不同训练种子模型下的簇分配之间两两ARI。
稳定性不等于语义正确。PCA/t-SNE/UMAP仅作可视化；二维图不作主证据。

## 指标边界
- ARI：主要外部聚类指标。
- AMI、NMI：辅助外部聚类指标。
- Silhouette：内部结构描述，不使用真实标签。
- 类内/类间距离与kNN purity：依赖测试标签，只能在分析冻结后事后计算。
- 运行时间与内存：效率描述，不作为聚类质量指标。

## XML可选扩展
XML后续核验文件匹配、坐标系、图像尺寸、类别字典、框/掩膜语义和冲突率后，才可开展注意力区域重叠分析。框只支持粗粒度区域关联，不证明形态或因果。未核验前不在摘要和结论承诺。

## 证据边界
ARI/AMI/NMI变化支持图像级留出集上的已知K聚类变化，不支持跨底片泛化；几何变化支持特征结构变化，不证明注意力机制的因果解释；稳定性不保证语义正确。Wang等（2025）已研究注意力与缺陷/非缺陷特征簇，本研究的潜在差异在于目标域自监督训练和训练规模控制，不能声称首次研究注意力或特征聚类。
